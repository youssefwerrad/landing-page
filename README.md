# Landing Page

A landing page built from a provided design spec, as part of The Odin Project's Foundations course. Built with plain HTML and CSS (Flexbox), no frameworks.

## Skills demonstrated
- Semantic HTML structure
- CSS styling from a design spec (colors, typography, spacing)
- Flexbox layout for header, info cards, and call-to-action sections
- Working with Google Fonts
